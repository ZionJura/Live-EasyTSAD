# TSAD Reproduction Harness — Design (v0.1, initial simplified framework)

Automates: find a TSAD paper → reproduce it as an EasyTSAD method in its own uv
environment → evaluate with the *existing* LiveLeaderBoard pipeline → fill the
leaderboard and rebuild the site → keep a complete, analyzable record including
human corrections.

## 1. Principles

1. **Do not fork the agent.** The DeepSeek Harness (DSH) agent loop, session
   JSONL, compaction, bash/fs tools and MCP client are used unchanged through the
   `dsh` binary from PyPI (`deepseek-harness-runtime-bin`, bundled Node, lives in
   `envs/harness`). Trimming is done by *profile composition*
   (`dsh/trim.patch.yml` disables ~40 rows of the shipped `headless` profile), not
   by editing DSH source. `EasyTSAD/tsautoreproduce-harness/` is a read-only
   reference copy of the DSH source (upstream `fcc0ad4621`, git link removed).
2. **The harness owns control flow; the model owns code.** A deterministic phase
   state machine (`task.py`) decides what the agent is asked to do and whether a
   phase is finished (machine-checked exit conditions in `validate.py`). The
   agent never decides that a phase is done.
3. **Only the integration is new code.** The method lives in
   `EasyTSAD/Methods/<Name>/` like every other method; evaluation, metrics,
   result layout and export are the existing `scripts/tsad exp` +
   `LiveLeaderBoard/pipeline` (never modified; enforced by the file guard).
4. **Faithfulness over scores.** A low metric is never a repair trigger. Repairs
   are triggered by typed failures (algorithm / environment / adapter / resource)
   and the reproduction contract records what the paper fixes.
5. **Everything is recorded.** DSH session JSONL (full model/tool trace) + task
   `journal.jsonl` (every harness action) + `corrections.jsonl` (human input with
   a context snapshot) live in the task directory.

## 2. Modules and phases

```
 harness search/new          harness run                          harness eval / report / publish
┌────────────────┐  ┌──────────────────────────────────────┐  ┌──────────────────────────────────┐
│ 1 Paper search │  │ 2 Reproduction (DSH agent, per phase) │  │ 3 Results + leaderboard          │
│   & download   │─▶│ EVIDENCE → IMPLEMENT → SMOKE          │─▶│ EVALUATE → REPORT → publish site │
│ papers.py      │  │ pipeline.py agent.py tools.py         │  │ runner.py report.py              │
└────────────────┘  │ validate.py guard.py runner.py        │  └──────────────────────────────────┘
                    └──────────────────────────────────────┘
          4 Human correction & records (review.py): approve / correct / log, corrections.jsonl
```

| Phase | Kind | Does | Exit condition (validate.py) |
|---|---|---|---|
| FETCH | deterministic | resolve paper, download PDF→`paper/paper.md`, clone code→`code/` | `paper/paper.md` non-empty |
| EVIDENCE | agent | read paper/code, call `mcp__tsad__save_contract` | `contract.json` valid against schema |
| *(review gate)* | human | `harness approve` or `harness correct` | configured in `[human].review_after` |
| IMPLEMENT | agent | write method folder, pick/create uv env, register, `scripts/tsad check` | structure + `src/` free of EasyTSAD imports + import check passes + guard clean |
| SMOKE | agent | `mcp__tsad__run_smoke`, repair typed failures | latest smoke run `success`, finite scores, guard clean |
| EVALUATE | deterministic | `scripts/tsad exp <task>/runs/eval.toml` (detached) | all (method, dataset) runs success |
| REPORT | deterministic | catalog entry, `scripts/tsad export`, `report.md` | method present in `benchmark.json` |

Agent phases run inside **one DSH session** (`--session-id` resume), so context
carries over; DSH compaction keeps it bounded. A failed exit check re-prompts the
same phase with the validator message (`[budget].max_repair_rounds`). Budget
(steps, wall clock) is enforced by `agent.py` from the event stream.

## 3. Method artifact (what the agent writes)

```
EasyTSAD/Methods/<Name>/
├── __init__.py          from .<Name> import <Name>
├── <Name>.py            adapter: class <Name>(BaseMethod); only shape/lifecycle/score alignment
├── config.toml          [Data_Params] + [Model_Params.Default] = the recipe (single source of truth)
├── src/                 algorithm, NO `EasyTSAD` imports (portable, copied/adapted official code)
│   └── __init__.py ...
└── REPRODUCTION.md      generated by report.py from the contract + notes
```

Environment: reuse an existing env (`torch2`, `legacy`) when the method's
dependencies are already there (just add the method to `methods` in
`envs/registry.toml`); otherwise `scripts/tsad new <env> --python X.Y --methods
<Name>` + `scripts/tsad add <env> pkgs...`. Never add packages to a shared env.

## 4. Interfaces (module contracts)

All modules live in `EasyTSAD/Harness/tsad_harness/`, run in `envs/harness`
(Python 3.11), import `config.load()`, `config.ROOT`, `task.Task`. Docs/comments
in English.

### config.py / task.py / agent.py (core, done)
- `config.load() -> Config`; `Config.network_env()`, `Config.agent_env()`,
  `Config.path(section, key)`, `.tasks_dir`, `.methods_dir`, `.dsh_bin`, `.python_bin`, `.api_key()`.
- `Task.create(method, paper=dict, code_url=, env_hint=, family=)`, `Task.open(id)`,
  `Task.all()`, `.dir`, `.method`, `.method_dir`, `.phase`, `.status`,
  `.set(phase=, status=, reason=..., **extra)`, `.log(event, **data)`,
  `.journal()`, `.counter(name)`, `.bump(name)`, `.spec` (task.toml), `.state`.
- `agent.run_agent(task, prompt, label=) -> RunResult(session_id, reason, final_text, steps, tool_calls, usage, error, events_path, ok)`.

### papers.py (module 1)
- `search(query: str, *, limit=10, sources=("arxiv","llm")) -> list[dict]` — candidates
  `{title, authors, year, venue, arxiv_id, url, pdf_url, abstract, code_urls, source}`.
  Sources: arXiv API (`export.arxiv.org`, direct), GitHub repo search (`api.github.com`,
  via proxy) for code, and an LLM web-search fallback through the configured
  Responses endpoint (`tools=[{"type":"web_search"}]`, JSON answer). S2/OpenAlex are
  optional (rate-limited without keys).
- `resolve(*, arxiv: str|None, title: str|None, pdf: Path|None, url: str|None) -> dict`
  — one paper record (same keys).
- `fetch(task: Task) -> dict` — download PDF to `paper/paper.pdf` (or copy a local
  one), extract text with PyMuPDF to `paper/paper.md` (page markers `<!-- page N -->`),
  write `paper/meta.json`; find GitHub links in the abstract/text when `code_url`
  is empty; `git clone --depth 1` the code into `code/<repo>` and record its commit
  in `paper/meta.json`. Returns the meta dict. Must work with the proxy rules in
  `config.network_env()` (httpx with `trust_env`, environment from network_env).

### guard.py + validate.py + runner.py + tools.py (module 2)
- `guard.baseline(task)` — snapshot (path, size, mtime_ns, sha1 for files < 2 MB)
  of every file under `[protect].paths` plus every `EasyTSAD/Methods/*` folder other
  than the task's, plus `envs/*/` other than the method's env (excluding `venv/`)
  → `guard/baseline.json`. `guard.check(task) -> list[str]` — changed/added/deleted
  protected paths. `guard.restore_hint(paths) -> str`.
- `validate.contract(task) -> list[str]` (errors; empty = ok),
  `validate.implementation(task) -> list[str]`, `validate.smoke(task) -> list[str]`,
  `validate.evaluation(task) -> list[str]`. Contract JSON schema: `CONTRACT_SCHEMA`
  in `validate.py` (see §5).
- `runner.method_env(method) -> str|None` (from `envs/registry.toml`),
  `runner.write_spec(task, kind: "smoke"|"eval", **overrides) -> Path`,
  `runner.run_smoke(task, *, epochs: int|None) -> dict` — writes
  `runs/smoke.toml`, runs `scripts/tsad exp <spec> --methods <M> --force`
  synchronously with timeout, then returns
  `{status, run_dir, metrics_summary, error, failure_class, log_tail, score_check}`;
  `runner.launch_eval(task, gpus: str) -> dict` (detached `setsid nohup`,
  log under `runs/eval-<ts>.out`, returns pid + run log path),
  `runner.eval_status(task) -> dict`, `runner.classify_failure(text, method) -> str`
  ∈ {`ALGORITHM_IMPLEMENTATION`, `ENVIRONMENT`, `ADAPTER_INTERFACE`,
  `RESOURCE_EXECUTION`, `UNKNOWN`}, plus the allowed-edit scope per class.
- `tools.py` — stdio MCP server (`python -m tsad_harness.tools`, FastMCP from the
  `mcp` package) reading `TSAD_TASK_DIR`. Tools (model sees `mcp__tsad__<name>`):
  `task_info()`, `save_contract(contract: dict)`, `record_note(kind, text, contract_id="")`
  (kind ∈ deviation|assumption|issue), `check_method()` (runs `scripts/tsad check <env>`
  limited to output lines of this method), `run_smoke(epochs: int|None)` (counts
  against `[budget].max_smoke_runs`), `ask_human(question)` (appends to
  `questions.jsonl`, sets a flag the pipeline turns into AWAITING_HUMAN after the run).
  Every tool call is also logged to the task journal (`tool/<name>`).

### report.py (module 3)
- `catalog_entry(task) -> dict` and `write_catalog(task)` — add/update
  `[methods.<Name>]` in `LiveLeaderBoard/catalog.toml` with tomlkit (comment
  preserving): `name, family, description, color` (+ `paper_title, paper_url,
  venue, year, code_url, reproduced_by = "tsad-harness"`). Colors: deterministic
  from the name, distinct from existing colors, `#rrggbb`.
- `export() -> Path` — `scripts/tsad export`, returns benchmark.json path.
- `write_report(task) -> Path` — `report.md` + `EasyTSAD/Methods/<Name>/REPRODUCTION.md`
  (paper, contract table with status explicit/inferred/unspecified, deviations and
  assumptions from notes, env, smoke + eval metrics table, corrections summary).
- `publish(*, build=True, deploy=False) -> dict` — export, copy
  `LiveLeaderBoard/results/benchmark.json` to `leaderboard/public/benchmark.json`,
  `npm run build` in `leaderboard/` when `build`, run the deploy script only when
  `deploy` is explicitly requested.
- Web app change (leaderboard/src/App.tsx, minimal): on mount fetch
  `${import.meta.env.BASE_URL}benchmark.json`; if it passes `validateBenchmark`,
  `setData` it; otherwise keep `demoBenchmark` silently.

### review.py (module 4)
- `snapshot(task) -> dict` — context for later analysis: phase/status, session id,
  last N (default 30) events of the latest DSH run (tool calls + results truncated),
  last agent final text, `git status --porcelain` of the method dir + env, latest
  smoke result, open questions.
- `correct(task, note, *, phase=None, author=None) -> dict` — append
  `{at, author, phase, note, target_phase, snapshot}` to `corrections.jsonl`, log
  `human/correct`; optionally rewind `phase`; status → READY. The next agent run
  receives all un-consumed corrections at the top of its prompt (then marked consumed).
- `approve(task, note="")` — clears a review gate (log `human/approve`), status → READY,
  phase → next.
- `pending_corrections(task) -> list[dict]`, `mark_consumed(task, ids)`.
- `answer(task, question_id, text)` — answers an `ask_human` question (stored as a correction).
- `history(task, n=50) -> str` — human-readable timeline from journal + corrections.

### pipeline.py + cli.py (orchestration)
- `pipeline.step(task)` executes the current phase once; `pipeline.run(task)` loops
  until DONE, AWAITING_HUMAN or FAILED.
- CLI (`scripts/harness <cmd>`): `search`, `new`, `run`, `status`, `approve`,
  `correct`, `answer`, `log`, `eval`, `report`, `publish`, `doctor`.

## 5. Reproduction contract (`contract.json`)

```json
{
  "method": "Name",
  "paper": {"title": "...", "arxiv_id": "...", "venue": "...", "year": 2022},
  "task_type": "UTS|MTS|both",
  "summary": "two-sentence description of the algorithm",
  "claims": [
    {"id": "model.window_size", "value": 100, "status": "explicit|inferred|unspecified",
     "source": "Sec. 4.1 / Table 5 / code: solver.py:L42", "mutable": false}
  ],
  "score": {"definition": "how the anomaly score is computed", "alignment": "how scores map to timestamps"},
  "dependencies": ["torch>=2", "..."],
  "official_code": {"url": "...", "commit": "...", "used_files": ["model/AnomalyTransformer.py"]},
  "open_questions": ["..."]
}
```

Required claim ids (at least): `data.preprocess`, `data.window_size`,
`model.architecture`, `train.optimizer`, `train.lr`, `train.epochs`,
`train.batch_size`, `score.function`, `threshold.protocol`. Thresholding itself
belongs to EasyTSAD's evaluation; the claim only records what the paper did.

## 6. Records

| File | Writer | Content |
|---|---|---|
| `dsh/sessions/**/session.v4.jsonl` | DSH | every message, tool call/result, step/turn, compaction (uncompressed) |
| `dsh/runs/NNN-<label>.{prompt.md,ndjson,stderr}` | agent.py | the prompt sent and the streamed run events |
| `journal.jsonl` | all modules | state changes, validations, tool calls, eval launches, reports |
| `notes.jsonl` | agent via MCP | deviations / assumptions / issues |
| `corrections.jsonl` | review.py | human input + context snapshot |
| `questions.jsonl` | agent via MCP | questions for the human |
