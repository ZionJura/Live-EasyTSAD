## Contract

- Task type: UTS
- Summary: CrossAD reconstructs finer time-series resolutions from coarser average-pooled resolutions using scale-independent Transformer encoding, cross-scale masked decoding, and a hard-routed query library with a shared EMA context bank. This contract follows the official TSB-AD-U code path: each input partition is standardized independently, interpolated squared reconstruction errors are summed across target scales, and the final timestamp scores are min-max scaled.
- Score definition: Let E_i=(X_i-Xhat_i)^2 for target scales i=1..m. The official model returns S(t)=E_m(t)+sum_{i<m} interpolate_linear(E_i,window_size)[t], without 1/m. Concatenate real timestamp scores, take the channel mean (identity for UTS), then apply sklearn MinMaxScaler(feature_range=(0,1)) once to the complete returned test-score vector, following run_TSBAD.py:L24-L29.
- Score alignment: Return chronological scores from full non-overlapping windows covering the test suffix beginning at N mod window_size; returned length floor(N/window_size)*window_size aligns correctly from the end in EasyTSAD. Independently standardize the full test array before trimming. For N<window_size, standardize real input, left-pad with its first value, infer once and remove synthetic-position errors before final min-max scaling. Suffix alignment and short-series padding are explicit integration departures from the official loader's prefix windows.
