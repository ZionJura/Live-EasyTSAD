## Contract

- Task type: both
- Summary: DIF maps time-series windows into an ensemble of randomly initialized, optimization-free dilated residual CNN representations and builds random axis-parallel isolation trees in each representation space. Deviation-enhanced anomaly scoring combines isolation path lengths with mean absolute deviations from visited split thresholds, with higher scores indicating stronger anomalies.
- Score definition: For each test window, obtain its fixed random CNN representation under each of the 50 networks, independently standardize the collection of test-window representations per network and apply tanh, then traverse the 6 isolation trees associated with each representation. For all 300 trees, collect raw traversed edge length h and mean absolute visited-split deviation g, including zero deviations in the mean. Return 2^(-mean_all_trees(h)/c(min(256,n_train_windows)))*mean_all_trees(g), following paper Eq. (8) rather than the official code's per-representation score average; do not add the code's leaf-population path correction. Larger scores indicate anomalies. No label-dependent postprocessing is part of this score.
- Score alignment: One score per full contiguous 100-point test window at stride 1, assigned to its final timestamp. Return a one-dimensional NumPy array of length N_test-99 and let EasyTSAD align it to the end of the test series, omitting the 99 artificial leading zeros used in the standalone official runner.

## Deviations, assumptions and issues

### Deviations

- Paper Sec. 5.2.2 Eq. (8) and Algorithm 2 integrate both path length and deviation over the full forest T (T=r*t). Official algorithms/dif.py:L245-L275 averages per-representation scores; _cal_score at L454-L463 first computes a depth exponential times mean deviation within each six-tree representation forest. These expressions are generally unequal. Follow the paper: aggregate path lengths and deviations over all r*t trees, then multiply the two terms. (claim `score.function`)
- Paper Sec. 5.2.2 Eq. (7) and Algorithm 2 define the arithmetic mean of absolute split deviations over the traversed split nodes, including exact-zero deviations in the node count. Official algorithms/dif.py:L420-L421 instead counts only nonzero deviations and adds 1e-6. Follow the paper: divide by the number of visited internal split nodes; define deviation as zero for a tree with no split nodes. (claim `score.deviation_mean`)
- Paper Sec. 5.2.2 Eq. (8), Sec. 5.3 and Algorithm 2 use the recorded traversed path length |p| and do not specify a terminal-leaf correction. Official algorithms/dif.py:L396-L399 adds c(n_samples_leaf) to the number of traversed edges. Follow the literal paper definition: use traversed edge count without adding the leaf-population correction. Retain standard iForest c(sample_size) as the score normalizer, whose numerical implementation is supplied by official code. (claim `score.path_length`)
- Paper Sec. 6.1.4 reports threshold-free AUC-ROC and AUC-PR without specifying label-based segment adjustment. Official utils.py:L199-L220 and L268-L281 replace scores within labeled anomalous segments by the segment maximum and return adjusted metrics, also computing best-test-label F1 in L135-L149. The reproduction returns raw DEAS scores and delegates all thresholding, adjustment and metrics to the fixed EasyTSAD/LiveLeaderBoard evaluator; it never reads test labels. (claim `threshold.protocol`)

### Assumptions

- Use independent CNNs for the time-series backbone, following main_ts.py:L39-L48 (new_ensemble_method=0) and algorithms/dif.py:L214-L229. Paper Sec. 5.2.1 derives CERE using layer weight matrices and Sec. 5.4.1 analyzes its MLP implementation, but gives no concrete CERE convolutional implementation for time series; Sec. 6.1.3 only specifies the TS2Vec-like dilated residual CNN. Do not transfer the tabular MLP CERE setting to the CNN. (claim `model.ensemble_method`)
- Neither paper nor main_ts.py/utils.get_sub_seqs specifies handling a split shorter than the 100-point window. Neutral default: require at least window_size observations in each split used for fitting/scoring and raise an informative error otherwise; do not shorten the window, fabricate observations, or silently change the architecture. (claim `data.short_series_policy`)
- For trees with no internal split nodes, Eq. (7) is undefined. Neutral convention: path length=0 and mean deviation=0, yielding zero contribution to the deviation average; if the forest normalizer c(min(max_samples,n_train_windows)) is zero, return zero anomaly scores. This is consistent with no available isolation evidence and the zero-filled deviation arrays / skipped one-node trees in algorithms/dif.py:L355-L370, while avoiding the official 0/0 in L454. (claim `score.degenerate_tree`)
